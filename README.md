# 🎃 Праздничная книга для Влады (Minecraft Birthday Book)

Интерактивная поздравительная книга к 16-летию Влады, выполненная с аутентичным интерфейсом и звуками из **Minecraft (Written Book)** в хэллоуинском стиле.

---

## ✨ Особенности
- 📖 **100% Minecraft Written Book UI**: точные пропорции, текстуры пергамента, шрифты Minecraft Default и Monocraft.
- 🔊 **Оригинальные звуки**: щелчки и шелест страниц (`item.book.page_turn`) из ванильной игры с вариацией тембра.
- 📜 **29 страниц поздравлений**: все тёплые пожелания от друзей, каждое поздравление на своей странице с подписью автора.
- 📑 **Интерактивное оглавление**: быстрый переход к любому автору.
- ⌨ **Управление клавиатурой**: стрелки `←`/`→`, клавиши `A`/`D`, `Home`/`End`.
- 🎃 **Halloween Edition**: пиксельный светильник Джека с мерцанием свечи в верхнем углу книги, паутинки, мистические угольки и частицы.
- ⏳ **Таймер доступа**: автоматический обратный отсчёт до 14 октября 21:59 МСК и скрытый режим предпросмотра для создателей (по ключу или параметру `?preview=1`).
- 🎉 **Праздничные эффекты**: запуск конфетти.

---

## 🚀 Быстрый запуск

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка продакшн-версии
npm run build
```

## 🌐 Развёртывание на Vercel

1. Перейдите на [vercel.com](https://vercel.com)
2. Нажмите **Add New...** -> **Project**
3. Выберите репозиторий `leg1tovskiy/vlada`
4. Нажмите **Deploy** — проект развернётся автоматически за 10 секунд!
